# Changelog

## 1.0.0 - Unreleased

- Added byte-span mutation discovery based on Glance.
- Added compiler validation and delta-debugging of invalid candidates.
- Added isolated snapshot execution for Erlang, Node.js, Deno, and Bun.
- Added bounded parallel workers, process-tree cleanup, and exit 130 propagation.
- Added stable mutant identifiers, reusable cache, terminal/JSON/GitHub reports.
- Added deterministic Stryker report-schema 3.9.0 projection and configurable
  `mutation.json`/`mutation.html` project reports with lossless native v1 data.
- Added the stable command tree, parent project discovery, canonical workspace
  locks, zero-mutant classification, deterministic policy, and bounded output.
- Added a single-file offline Mutation Testing Elements 3.9.0 HTML report with
  escaped data, CSP hashes, vendored provenance, and four-runtime byte parity.
- Added safe configurable report storage, snapshot/digest exclusion, atomic
  replacement, source-overlap and reparse-point rejection.
- Added unpublished Hex, escript, npm, checksum, and CycloneDX build gates.
