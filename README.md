# Gleam_mutants

Mutation testing for Gleam through a library and CLI.

## Installation

```sh
git clone https://github.com/P4suta/gleam-mutants.git
cd gleam-mutants
mise install
mise x -- gleam deps download
```

## Usage

```sh
mise x -- gleam run -m gleam_mutants -- run --root path/to/project
```
